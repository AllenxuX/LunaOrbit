# 管理控制台改版与实验只读接入

用户授权直接操作并完成自测，不等待逐步确认。使用frontend-design、vue-best-practices及独立任务并行技能；沿用现有未提交工作区，不自动提交或推送。

## 设计

深蓝侧栏 #17243b、工作区 #f3f5f9、内容白 #ffffff、主色 #2563eb、正文 #263449、次级文字 #738198。中文优先使用系统可用的苹方/等线/微软雅黑，拉丁为Segoe UI，数字使用tabular-nums；不依赖外部字体服务。正文14px，标题24px，节标题16px。4/8px间距系统，控件36px、表行52px、小圆角6px。左对齐的信息型界面，减少大幅提示与无关装饰。

```
品牌/收起侧栏 | 面包屑、导航菜单、当前数据源、身份入口
总览          | 页面标题 / 描述                     主操作
Kafka集群     | 数据概况（有真实查询才展示数值）
同步拓扑      | 筛选 / 工具栏
身份权限      | 表格或拓扑工作区 / 证据侧栏
受控变更      | 分页 / 采样来源及时间
```

审视：企业后台本就需要稳定的导航/表格规范，因此保留这一熟悉骨架；以Kafka→MM2→Kafka的方向表达、证据分层和显式未知区分本平台，避免套用无依据的流量图、健康百分比或营销Hero。数据源标记必须来自后端，视觉状态不能冒充外部健康。

## 边界与责任

- App仅组合侧栏/顶栏/路由；Runtime composable维护公共数据源状态及卸载取消。
- Overview请求自己的登记及发现摘要，显示真实total；API不可用/无快照时显示未知和可执行入口。
- 现有页面统一page-header/panel/filter-bar/data-table，保留已有CAS、登录隔离、X6及表单交互；演示场景仅在Mock时显示。
- 后端显式readonly-lab接入经实测v0.16.0 Decoder、实际Kafka Reader/Prober和固定配置scope；默认Mock保留，生产写保持禁用。
- 实验Go API与nginx同Pod，nginx提供Kite localhost代理及前端同源代理；只经回环port-forward/SSH隧道接入，不暴露凭据。
