- [x] ELK固定端口正交布局，Worker隔离、超时、取消及过期结果保护。
- [x] 固定右输出/左输入；缓存路线，轻微拖动保留通道；仅更新关联和实际受遮挡路线。
- [x] 节点重叠落点就近避让；无可行清晰路线时回退，不静默穿节点。
- [x] X6增量更新，拖动不resetCells、不自动缩放、不移动无关节点；显式整理布局才全局重排。
- [x] 保存/刷新保持节点坐标和固定端口，按保存坐标确定性重建路线；路径聚焦、健康标识、实例视图不回退。
- [x] Mock真实浏览器10/30/100px连续拖动、跨层拖动、障碍、串联、双向、密集图及截图复核。

边界：任意拖动无法同时保证零交叉和完全自由；产品保证稳定、真实方向、阻挡避让及清晰失败回退。默认不因拖动重新排列其他节点，整体交叉优化由用户点击整理布局触发。

持久化边界：沿用现有个人View契约，只保存节点坐标和模式隔离键。拖动过程保留的局部通道属于当前会话，不持久化路线历史；重新加载按保存坐标重新避障，不承诺与多次拖动后的每个折点逐一相同。
