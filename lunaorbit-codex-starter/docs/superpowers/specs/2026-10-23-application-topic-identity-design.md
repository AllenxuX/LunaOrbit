# 应用、账号与Topic绑定

用户选择通过应用、Kafka账号和Topic绑定记录生产来源，并明确继续开发。扩展现有信息登记，不恢复旧权限领域。应用新增可选location（512字节），关系新增可选account及client_id（各256字节）；消费关系保留consumer_group。账号仅名称，不存密码，不验证认证或ACL。不同集群、不同账号的关系不合并。JSONB兼容旧记录，无需迁移。

表单与列表登记部署位置、账号、Client ID；Topic链路应用详情显示位置/负责人，关系详情显示账号/Client ID。采用关系属性而非额外账号节点，保持图简洁。所有绑定证据为人工登记，不代表实际流量。保留revision、严格字段白名单、输入上限和敏感字段拒绝；不修改Kafka/MM2。原生消费组查询不变。
